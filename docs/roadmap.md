- [x] 只发现稳定标签；数字排序；不降级；跨系列需维护者确认。
- [x] 候选分支 rebase；不改写 main；冲突保留且不更新依赖锁。本地真实 Git 测试通过。
- [x] 每 6 小时检查的工作流已启用；手动执行无更新路径通过；默认 token 只读，草稿 PR 权限已获授权。
- [ ] 新版本候选的远程 rebase、去重同步 PR、过期候选处理的实际运行证据；未经验证不得发布。
- [x] 待审同步 PR 的系统/验证指纹、真实 Git 来源检查、并发 main/PR 复查；本地真实 Git＋模拟 API 验证，实际 GitHub 候选 PR 路径仍待新上游版本触发。
- [x] SQLite 驱动正式发行的独立发现、SHA/ZIP 摘要验证及候选生成；升级移除过时文件，候选去重/取代同时比较核心和驱动版本。
- [x] 固定集成 SHA 构建 ZIP，重复构建校验和相同，核心文件保持原字节。
- [x] 在没有 MySQL 扩展的隔离 PHP 中完成 SQLite 安装与内容操作，不连接 MySQL 服务。

本地已验证 WordPress 7.1.3、驱动 3.1.0、PHP 8.4.26、SQLite 3.53.4。真实流程
包括安装、Unicode 内容/配置读写、自定义表 dbDelta、事务回滚、WAL/FULL、HTTP
首页/REST、后台登录、访客隔离、重复安装拒绝、数据库及 drop-in 遗失的 503。
GitHub CI 已在 Ubuntu 通过上述测试并上传开发包，手动同步确认无上游更新。
尚未观察首次 cron 触发或新版本同步 PR，详情见 [验证记录](verification.md)。
