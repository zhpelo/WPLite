# Web 安装与数据目录保护

这是开发版安装器，不代表已认证所有虚拟主机、TLS 终止方式或商店组合。不需要
服务器 SSH；需要可上传文件的主机管理面板，以及符合要求的 PHP/PDO SQLite。
目前不修改官方核心文件，也不会进入 MySQL 数据库配置向导。

## 准备一次性所有者密钥

公开安装页面不能证明访问者拥有站点。请先在自己的电脑上运行项目提供的工具：

```sh
python3 tools/prepare_web_install.py --directory /absolute/private/NEW-setup-directory
```

工具仅创建新的本地目录（0700）和两个文件（0600），不覆盖任何已有目录或链接：

- `setup-key.php`：只含 SHA-256 摘要及直接 HTTP 访问的 404 保护。
- `owner-secret.txt`：64 个随机十六进制字符的安装密钥，仅保留在本地。

工具不会把密钥打印到终端日志。通过文件管理器**仅上传 setup-key.php** 到网站的
`wplite/setup-key.php`，不要上传 owner-secret.txt。不要使用示例固定密钥、把密钥
写入 URL、提交到 Git 或交给第三方在线生成器。

上传文件的修改时间必须在一小时内；过期后重新生成/上传。FTP 若保留旧修改时间，
应确保密钥文件确实是刚刚生成的。成功安装后会删除服务器密钥文件，安装入口关闭；
即使删除失败，已有站点配置也会阻止再安装。可在主机面板中核实文件已删除。

## 安装

上传并解压开发 ZIP，然后通过 HTTPS 打开首页或 `wplite/install.php`。首页与官方
安装入口在未配置时都会转到 WPLite SQLite 安装器。填写所有者密钥、完整站点 URL、
标题、管理员账号/邮箱/密码和可选数据目录。URL 必须与当前域名、端口和安装路径
完全一致；子目录安装会使用服务器真实 DOCUMENT_ROOT 判断公开边界。

管理员密码至少 12 字节，安装密钥至少 32 个字母、数字、下划线或连字符。两者均只
通过 POST 传输，不在表单错误页回显。跨 Origin 请求、无效/过期密钥、并发安装、
已有配置及已有用户数据都会被拒绝。仅本机 loopback 测试允许 HTTP。反向代理需要
在可信服务器配置中正确设置 HTTPS，安装器不会信任任意 X-Forwarded-Proto。

站点专属配置位于 `wplite/site-config.php`；根目录 wp-config.php 为发行版不可变的
启动入口。备份或人工恢复时必须保留站点配置及数据目录，不能仅保存根入口。
旧开发构建的传统 wp-config.php 不会被安装器自动覆盖或迁移。

## 首选私有数据目录

填写已有、可写父目录下的**新绝对路径**，且位于真实公开根目录之外，例如
`/home/account/private/wplite-site`。路径不得含 `..` 或符号链接；数据必须在本机
磁盘，不能使用 NFS 等共享文件系统。不得通过 Alias、独立虚拟主机或下载接口把
该私有目录重新映射到公开网络。

## 只能写公开目录时

数据目录留空会尝试网站根目录下的 `.wplite-data`。安装器先只写不含秘密的准备
标记、Apache 拒绝规则及随机探针；**在验证保护前不创建 SQLite、站点身份或盐值**。

验证必须同时满足：公开位置能通过 HTTP 返回精确随机内容；数据目录内 SQLite、
WAL、SHM、JSON、隐藏文件和嵌套备份/回退路径全部返回 403/404，且不泄漏探针
内容。重定向、超时、500、错误站点/缓存响应都不能代替拒绝访问证明。检查不跟随
重定向，HTTPS 使用证书与主机名验证；服务器必须允许对本站发起 loopback HTTP(S)。
仅凭存在 .htaccess 文件不算通过。HTTP 自检需要空闲 PHP worker，单 worker
服务器可能超时并拒绝安装，而不是绕过保护继续写入。

Apache 2.4 需要允许该目录使用 `Require all denied`（例如 AllowOverride AuthConfig）。
Nginx 不读取 .htaccess，需由主机管理员拒绝整个目录及所有子路径；网站在根目录时，
可在对应 server 块中配置类似规则：

```nginx
location = /.wplite-data { return 404; }
location ^~ /.wplite-data/ { return 404; }
```

子目录网站要包含完整 URL 前缀。这里仅为配置示意，尚未完成真实 Nginx 安装矩阵。
配置后重试安装即可，安装器只复用自己创建、且没有数据库或其他未知文件的准备目录，
不会要求删除用户数据。主机无法提供整目录拒绝访问时，应改用私有目录或更换环境。

安装后保留拒绝规则。启动、备份和恢复检查其匹配摘要；规则文件缺失/修改会停止运行。
该检查不能自动发现外部 Nginx/Apache/CDN 配置随后改变，因此每次更换主机、修改
服务器规则或恢复目录权限都必须重新确认所有数据库和备份 URL 不可下载。
默认备份可在同一已验证目录内保存；任意其他公开目录仍不允许存放备份。
