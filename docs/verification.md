# 当前版本验证记录

本文件只记录精简 MU + drop-in 架构。旧发行平台的测试结论不能直接继承。

## 自动验证内容

- 依赖锁只有 SQLite，无 WordPress 集成 SHA；归档校验、路径、链接、重复项、
  大小限制及准备目录拒绝覆盖；仅保留只读兼容性工作流。
- 真实 PDO SQLite，无 mysqli/pdo_mysql；全新站点配置不修改官方原始文件。
- 原生 WordPress 安装、中文/emoji CRUD、序列化配置、自定义表 dbDelta、事务回滚、
  WAL/FULL、站点健康信息；核心/插件/主题更新接口未被拦截。
- 官方 Core_Upgrader 使用已预先下载、按官网 MD5 清单核对的官方 ZIP，在临时站点
  执行真实文件升级；随后新进程运行 wp_upgrade()，检查数据、版本和核心字节。
- 升级后 HTTP 首页、REST、后台登录/访客隔离；数据库、drop-in、驱动缺失返回
  503 且不重新创建数据库；公开目录内数据和重复配置在写入前拒绝。

测试站通过独立 MU fixture 阻断外部 HTTP 和邮件。原生升级器使用本地官方包，
数据库升级由新进程明确执行；不把这当成公网下载、无人值守更新调度或主机全矩阵。
